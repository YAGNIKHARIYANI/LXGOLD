# 🥇 LX GOLD/SILVER RATES

> **Live 1-Second Real-Time Bullion Market Web Application**  
> Developed by **Yagnik Hariyani** & **Vaidehi Hariyani**

---

## ⚡ Overview
**LX GOLD/SILVER RATES** is a 100% real-time, API & WebSocket-driven bullion market web application. It delivers live gold and silver prices across **36 States & Union Territories** and **679 Indian Cities** with real-time stock-trading style tick flash animations.

---

## ✨ Features
- **100% Real-Time Live Feed**: Zero mock, fake, or simulated data.
- **Stock Market Live Tick Highlighting**: Prices dynamically flash **Vivid Dark Green (`#14532d`)** on price increases and **Vivid Dark Red (`#7f1d1d`)** on price decreases.
- **Real-Time Persistent EventStream (SSE)**: Sub-second live updates without needing to reload the page.
- **Complete Indian Market Coverage**: Integrated with 36 States and 679 Cities from the official Bullion market dataset.
- **Exact Purity Breakdown**: Live 24K (999), 22K (916), and Fine Silver reference rates with GST calculations.
- **Clean 3-Column Responsive Design**: Edge-to-edge full-width fluid layout for desktops, laptops, tablets, and mobile devices.

---

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YAGNIKHARIYANI/LXGOLD.git
   cd LXGOLD
   ```

2. **Start the server:**
   ```bash
   python server.py
   ```

3. **Open in browser:**
   Open [http://localhost:8080](http://localhost:8080) in your web browser.
